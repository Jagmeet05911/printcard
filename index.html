1. Apni file chuno

Image jaan PDF upload karo. PDF vich filhaal pehla page process hovega.

2. Card da preview

File upload karan te preview ethe aavega

3. Crop adjust karo

Auto crop pehlan koshish karega. Je border galat hove, sliders naal crop theek kar lao.

4. Download karo

Image JPG format vich download hovegi. Quality high rakhan di koshish kiti gayi hai.
